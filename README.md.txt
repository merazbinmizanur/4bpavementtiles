# 4B PAVEMENT TILES — সেটআপ ও পাবলিশ গাইড

অ্যাপ সম্পূর্ণ তৈরি হয়ে গেছে। লাইভ করার আগে নিচের ধাপগুলো একবার শেষ করে নিতে হবে (প্রতিটা মাত্র একবারই করতে হবে)।

---

## ধাপ ১ — Email/Password লগইন চালু করা

Firebase Console → আপনার প্রজেক্ট (`b-pavement-tiles-d6a53`) → **Authentication** → **Sign-in method** → **Email/Password** সিলেক্ট করে **Enable** করুন → Save।

---

## ধাপ ২ — Firestore Rules পাবলিশ

Firestore Database → **Rules** ট্যাব → এই ফোল্ডারের `firestore.rules` ফাইলের পুরো কনটেন্ট কপি করে পেস্ট করুন → **Publish**।

(Database তৈরির সময় অবশ্যই **Production mode** সিলেক্ট করবেন — আগে যেমন বলা হয়েছিল।)

---

## ধাপ ৩ — মালিকের (আপনার) প্রথম অ্যাকাউন্ট তৈরি — ম্যানুয়াল, একবারই

অ্যাপের ভেতর থেকে শুধু **নতুন ম্যানেজার** অ্যাকাউন্ট বানানো যায় (মালিক প্যানেল থেকে)। কিন্তু মালিকের নিজের প্রথম অ্যাকাউন্টটা Firebase Console থেকে হাতে বানাতে হবে:

**৩ক) Auth ইউজার তৈরি:**
Authentication → Users ট্যাব → **Add user** → আপনার ইমেইল ও পাসওয়ার্ড দিন → Add user চাপুন → তৈরি হওয়া **User UID** কপি করে রাখুন।

**৩খ) Firestore-এ role ডকুমেন্ট যোগ:**
Firestore Database → Data ট্যাব → **Start collection** → Collection ID: `users` → **Add document**:
- Document ID: এ ৩ক থেকে কপি করা UID পেস্ট করুন (নতুন কিছু টাইপ করবেন না)
- এই ফিল্ডগুলো যোগ করুন:
  | ফিল্ড | টাইপ | মান |
  |---|---|---|
  | name | string | আপনার নাম |
  | email | string | ৩ক-এ দেওয়া একই ইমেইল |
  | phone | string | ফোন নম্বর (ঐচ্ছিক) |
  | role | string | `owner` (হুবহু এই বানানে, ছোট হাতের) |
  | active | boolean | true |
  | createdAt | timestamp | এখনকার তারিখ/সময় |

এটা না করলে লগইন করার পরও অ্যাপ আপনাকে আবার লগইন পেজে ফেরত পাঠাবে (role না পাওয়ায়)।

---

## ধাপ ৪ — অ্যাপ হোস্ট করা (লাইভ করা)

দুটো সহজ অপশন:

**A) Firebase Hosting (সবচেয়ে সহজ, একই প্রজেক্টে, ফ্রি)**
কম্পিউটারে Node.js ইনস্টল থাকলে:
```
npm install -g firebase-tools
firebase login
firebase init hosting     (public directory হিসেবে এই ফোল্ডারটাই বেছে নিন)
firebase deploy
```

**B) Netlify / Vercel (GitHub ছাড়াই)**
তাদের সাইটে গিয়ে এই পুরো ফোল্ডারটা ড্র্যাগ-ড্রপ করলেই একটা লিংক পেয়ে যাবেন।

---

## ধাপ ৫ — টেস্ট করা

1. দেওয়া লিংক মোবাইলে ব্রাউজারে খুলুন
2. ৩ক-এ দেওয়া ইমেইল/পাসওয়ার্ড দিয়ে লগইন করুন → মালিক প্যানেল খুলবে
3. ব্রাউজার মেনু থেকে **"Add to Home Screen"** করলে এটা মোবাইলে অ্যাপের মতো ইনস্টল হয়ে যাবে
4. মালিক প্যানেল → আরও → স্টাফ থেকে ম্যানেজারদের অ্যাকাউন্ট বানিয়ে দিন — তারা সরাসরি লগইন করতে পারবে

---

## ফাইল স্ট্রাকচার (সংক্ষেপে)

- `index.html` — লগইন পেজ
- `owner.html` / `manager.html` — দুই প্যানেল
- `js/` — সব লজিক (Firebase, ডেটা, UI)
- `css/style.css` — ডিজাইন সিস্টেম
- `icons/`, `manifest.json`, `service-worker.js` — PWA (ইনস্টলযোগ্য অ্যাপ) সাপোর্ট
- `firestore.rules` — সিকিউরিটি রুলস (ধাপ ২ দেখুন)
